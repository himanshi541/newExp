 📰 NewsExplorer - React News App

A simple and elegant news application built using **React.js** and the **NewsAPI**. This app fetches real-time headlines and articles from multiple categories like Technology, Sports, Health, and more.



🚀 Live Demo

👉 [Click here to view the live app](https://your-live-url.netlify.app/)

✨ Features

- ✅ Fetches top news headlines using **NewsAPI**
- ✅ Category-based filtering (e.g., Technology, Sports)
- ✅ Responsive design for all screen sizes
- ✅ Modern React practices (hooks, components, props)
- ✅ Dark/light theme toggle (optional upgrade)
- ✅ Search functionality (optional upgrade)

---

🛠 Tech Stack

- **Frontend**: React.js, CSS 
- **API**: [NewsAPI.org](https://newsapi.org/)
- **Deployment**: Netlify
